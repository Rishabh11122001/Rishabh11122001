## Featured analytics projects

### 🤖 AI-Powered Data Analyst Copilot

Ask questions in plain English and explore a **99K-order PostgreSQL warehouse** through live data, charts and insights.

- Converts questions into validated SQL with destructive-query blocking and query timeouts.
- Includes Gemini-to-Groq fallback and **24 automated tests**.
- **Tools:** Python, PostgreSQL, Streamlit, Gemini, Groq, Plotly.

[Repository](https://github.com/Rishabh11122001/ai-data-analyst-copilot) · [Live app](https://ai-data-analyst-copilot-9dmnh4izbccbpgpuyur8e2.streamlit.app)

### 📊 E-Commerce Revenue & Operations Analytics

An end-to-end analytics project using the **Olist Brazilian e-commerce dataset**, SQL modelling and Power BI reporting.

- Transformed **9 raw datasets across ~99K orders** into a star schema with 4 dimensions and 4 fact tables.
- Reconciled **R$15.84M in order value** and investigated a **R$165K payment gap**.
- Built a **3-page Power BI dashboard** covering sales, products, delivery and customer experience.
- **Tools:** PostgreSQL, Power BI, DAX, Excel.

[Repository](https://github.com/Rishabh11122001/ecommerce-revenue-operations-analytics) · [Dashboard walkthrough](https://sweet-taffy-8a30d1.netlify.app/ecommerce-dashboard-demo.html)

### 📉 Customer Churn Analysis & Prediction

A customer analytics and machine-learning workflow built on a **2,000-customer synthetic dataset**.

- Combines data cleaning, exploratory analysis, feature engineering and customer segmentation.
- Trained Logistic Regression and Random Forest models with leakage-safe train/validation/test evaluation.
- Improved recall from **35% to 61%**, reaching **~92% after threshold tuning**; this metric measures churn detection, not overall accuracy.
- **Tools:** Python, Pandas, NumPy, SQLite, Scikit-learn, Matplotlib.

[Repository](https://github.com/Rishabh11122001/customer-churn-analysis-prediction) · [View analysis](https://sweet-taffy-8a30d1.netlify.app/churn_analysis.html)
